# Клуб четырёх коней 🏇

Адаптивный лендинг, выполненный в рамках тестового задания.

## 🔗 Демо

https://yandex-frontend-job-test.vercel.app/

## 📌 О проекте

Проект представляет собой адаптивный лендинг с интерактивными элементами и анимациями.

Реализовано:
- адаптивная верстка под разные разрешения экрана (desktop / tablet / mobile)
- слайдер секции «Участники турнира»
- адаптивный слайдер этапов
- анимации появления элементов при скролле
- бегущая строка

## 🛠 Технологии

- HTML5 (семантическая верстка)
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (vanilla JS)
- Intersection Observer API

## 📱 Адаптивность

Сайт корректно отображается на следующих разрешениях:
- 320px
- 768px
- 1200px+

## 📂 Структура проекта

```
/css
/js
/assets
index.html
```

## ⚙️ Запуск проекта локально

```bash
git clone https://github.com/cheschirsky/yandex-frontend-job-test.git
cd yandex-frontend-job-test
```

После этого открыть `index.html` в браузере.

## ✨ Особенности реализации

- разделение стилей по секциям
- кастомная логика слайдеров
- плавные анимации появления блоков при скролле
